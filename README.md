# Therennai

Therennai is an open-source AI agent that runs locally on your own computer.

This repository has the Windows desktop app, `Therennai.exe`. It's a chat window with a sidebar of recent chats, a message box and a model picker. The only model is **Therennai 1.0**. No model is connected to it yet, so it replies with a placeholder message.

## Requirements

- Windows 10 or 11
- [.NET 9 SDK](https://dotnet.microsoft.com/download/dotnet/9.0) to build
- Microsoft Edge WebView2 Runtime (already included with Windows 11 and most up-to-date Windows 10 PCs)

## Build and install

In PowerShell, from the repository folder:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

This builds `dist\Therennai.exe` and puts a **Therennai** shortcut on your desktop.

Chats are saved on your machine in `%LOCALAPPDATA%\Therennai`. Nothing is sent over the network.

## Project layout

| Path | Purpose |
|---|---|
| `src/Therennai/` | The native app (C# WinForms): window, icon, and WebView2 host for the interface |
| `ui/index.html` | Interface layout: sidebar, conversation, message box, model picker |
| `ui/styles.css` | Styling, with light and dark themes that follow Windows |
| `ui/app.js` | Chats, model list (`MODELS`) and the placeholder reply (`respond`) |
| `assets/icon.ico` | App icon, generated by `tools/make-icon.ps1` |
| `install.ps1` | Builds the exe and creates the desktop shortcut |

## Connecting a model later

Replace `respond()` in `ui/app.js` with a call to a local model, and add entries to `MODELS` to show them in the model picker.
